# letterbox-cinema

Outil gratuit et open source dans le navigateur pour ajouter des barres letterbox (cinéma scope) ou rogner des images et vidéos aux ratios cinématiques (2.39:1, 1.85:1, 2.00:1, etc.).

**Démo** : [https://salimadour31-boop.github.io/letterbox-cinema/](https://salimadour31-boop.github.io/letterbox-cinema/) (après activation de GitHub Pages)

## Fonctionnalités
- Import d'images ou de vidéos (traitement local, rien n'est envoyé)
- Ratios : 2.39:1 (Scope), 1.85:1 (Flat), 2.00:1, 16:9, 4:3
- Modes : Letterbox (ajoute des barres) ou Crop (rogne)
- Couleur des barres personnalisable
- Export PNG
- Interface responsive, multilingue (Français, English, Tamazight)
- Code simple, commenté, sans dépendances

## Usage
1. Ouvrez `index.html` ou la démo GitHub Pages.
2. Importez une image ou une vidéo.
3. Choisissez le ratio et le mode.
4. Cliquez sur Appliquer.
5. Téléchargez le résultat.

Pour les vidéos, l'outil capture actuellement une frame (extension possible avec MediaRecorder ou WebCodecs).
